# Aura Takı

GitHub Pages üzerinde çalışmak üzere hazırlanmış, Türkçe ve mobil uyumlu statik takı vitrini.

## Yayınlama

1. GitHub deposunda **Settings → Pages** sayfasını açın.
2. Kaynak olarak ana dalı (`work` ya da tercih ettiğiniz yayın dalı) ve `/ (root)` klasörünü seçin.
3. Kaydedin; siteniz GitHub Pages adresinde yayınlanır.

## Hızlı düzenleme

`script.js` içindeki `WHATSAPP_NUMBER` ve `INSTAGRAM_URL` sabitlerini kendi iletişim bilgilerinizle değiştirin. Ürünler aynı dosyadaki `products` listesinde bulunur; yeni ürün eklemek için listeye bir nesne eklemeniz yeterlidir.

## Görsel değiştirme

`script.js` içindeki `VISUALS` alanına logo, ana sayfa, hikâye, hakkımızda ve kategori görsellerinin URL'lerini yapıştırın. Her ürün için de kendi satırındaki `imageUrl` değerini değiştirin. URL boş kaldığında mevcut tasarımın CSS placeholder'ı korunur; böylece bir görsel eklemek için yalnızca URL değiştirmeniz yeterlidir.
